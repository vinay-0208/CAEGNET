## 1. Executive Summary & Purpose

This audit establishes the baseline state of the repository before executing Phase 5: **Original CAEG-Net Methodology Correction, Consistency Repair & Research-Guided Optimization**.

The central research question of CAEG-Net is:
> *"Can context-aware adaptive expert gating improve short-term electricity load forecasting by dynamically combining complementary LSTM, TCN, and CNN temporal experts?"*

During historical V2/V3 exploration, the expert family was experimentally substituted with GRU, TCN, and PatchTemporal/PatchLinear backbones, and extensive test-set evaluations were performed. This audit establishes the boundary between **canonical original architecture** and **historical exploratory research**, documents all identified methodological and implementation inconsistencies, and lays out the precise protocol for Phase 5.

## 3. Methodological Audit Findings

### 3.1 Expert Family Integrity
- **Identified Deviation**: During Phase 2–7, the original expert family (LSTM + TCN + CNN) was replaced by GRU + Causal TCN + PatchTemporal. While PatchTemporal provided strong point-estimate accuracy ($263\text{ MW}$ vs $469\text{ MW}$ for the undertrained V1 CNN), this diverted the core academic inquiry.
- **Restoration Mandate**: Phase 5 strictly restores the original **LSTM + TCN + CNN** expert family. No GRU, no PatchTemporal, no Transformer/Mamba additions.

### 3.2 Canonical Data & Windowing Protocol
- **Dataset**: Modern PJM regional load dataset (`data/Modern_PJM/pjm_load.csv`), 8,784 hourly rows (1 full leap year, 2023-10-01 04:00 to 2024-10-01 03:00 UTC).
- **Split**: 70% train (6,148 observations), 15% validation (1,318 observations), 15% test (1,318 observations). Strictly chronological, no random shuffling across partition boundaries.
- **Scaler**: `StandardScaler` fitted **exclusively on the training partition**. Validation and test are transformed using training parameters. Zero target leakage.
- **Windowing**: Model lookback $L=168$ hours ($X_t \in \mathbb{R}^{168 \times 1}$), forecast horizon $H=24$ hours ($Y_t \in \mathbb{R}^{24}$). Prepending history ($L-1=167$ observations) preserves partition boundary continuity without dropping valid target horizons.

### 3.3 Context Features & Recent Baseline Error
- **Original V1 Context (4D)**:
  1. Trend: Normalized OLS regression slope over 168h lookback: $\beta_1 / (\sigma(z) + 1e-6)$.
  2. Volatility: Standard deviation of first differences $\Delta z_i = z_i - z_{i-1}$ over 168h lookback.
  3. Periodicity: Lag-24 sample autocorrelation over 168h lookback ($r_{24}$).
  4. Recent Baseline Error: Out-of-sample MAE from a chronological walk-forward expanding Ridge regression baseline.
- **Identified Ambiguity**: Recent baseline error was occasionally mislabeled as "CAEG feedback" or "closed-loop feedback". In reality, it is a **recent baseline forecast error / difficulty signal** generated by an independent linear forecaster.
- **Causality Guarantee**: At origin $t$, recent baseline error evaluates forecasts completed at or before $t$ (origin $s = t - 24$ predicting $[t-23 : t]$). Targets $y_{t+1 : t+24}$ are strictly unobserved.

### 3.4 Baseline Matrix & Ground-Truth Reference
- **Frozen V1 Benchmark Reference (Seeds: 42, 123, 2024, 3407, 999)**:
  - $\text{MAE} = 251.44 \pm 9.74\text{ MW}$
  - $\text{RMSE} = 334.32 \pm 11.09\text{ MW}$
  - $R^2 = 0.8723 \pm 0.0086$
  - $\text{MAPE} = 4.71 \pm 0.21\%$
  - $\text{MSE} = 111,865.65 \pm 7,509.11\text{ MW}^2$
- **V1 Baseline Observations**:
  - Standalone LSTM: $301.45 \pm 19.17\text{ MW}$
  - Standalone TCN: $259.86 \pm 8.54\text{ MW}$
  - Standalone CNN: $469.53 \pm 58.34\text{ MW}$ (Severely undertrained in V1)
  - Static Equal Ensemble: $295.48 \pm 15.54\text{ MW}$ (Severely degraded by the broken CNN)
  - Persistence Naive-24: $285.19\text{ MW}$

### 3.5 Statistical Implementation Audit
- **Identified Flaw in Historical Tests**:
  - In earlier phases, Diebold-Mariano tests were computed on raw hourly sequences without proper HAC/Newey-West variance estimation, producing artificially extreme $z$-scores ($|\text{DM}| > 15$) and conflicting with paired $t$-tests.
  - Furthermore, hourly overlapping 24-step horizons were treated as independent observations, severely violating independence assumptions.
- **Correction Required**:
  - Construct $K=53$ non-overlapping daily forecast blocks ($53 \times 24 = 1,272$ hours) for rigorous paired testing.
  - Employ Harvey-Leybourne-Newbold (HLN) small-sample corrections for multi-step DM statistics.
  - Apply Holm-Bonferroni family-wise error rate control across all paired comparisons.

### 3.6 Test Set Contamination & Methodology Reset
- **Reset Mandate**: Historical test performance must **NEVER** be consulted during Phase 5 model selection.
- All candidate ablations, hyperparameter choices ($\rho$, $\tau$, learning rates, regularization constants), context features, and routing mechanisms must be selected **strictly using Validation MAE**.
- The test partition is permanently locked until a single Phase 5 candidate is frozen.
